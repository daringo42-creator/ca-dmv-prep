# California Class C knowledge-test prep

A single-page study dashboard for the California DMV Class C written knowledge test,
written for out-of-state license holders transferring residency.

**Live site:** https://daringo42-creator.github.io/ca-dmv-prep/

- 208 practice questions across 11 topics, each carrying a source link and a confidence label
- Mock exams in the real format: 36 questions, 6 wrong allowed
- A move checklist with the 10-day license / 20-day registration deadlines
- The 2025-26 rule changes that older study guides still get wrong
- Sources and caveats stated openly, including one unresolved source conflict

Everything is in `index.html` — one self-contained file, no build step, no dependencies,
works offline. Progress is stored in the visitor's own browser only.

Built from the California Driver's Handbook, the California Vehicle Code and published
DMV pages. A study aid, not legal advice.
